# 0sfs/.github

Shared contribution guidance for every repository in the 0SFS organization: the code of conduct, the contributing guide, the security policy, and the pull-request template.

Each repository's AGENTS.md points here. Versions are named `YY.MM.DD#N` from the git history, as [CONTRIBUTING.md](CONTRIBUTING.md) describes. That form does not fit `package.json`, so a package's `version` field is not the repository version.
