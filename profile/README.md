# 0SFS — Open Source Flight Simulator

A real-world flight simulator that runs in a browser tab, with JSBSim flight physics over real-world scenery. Nothing to install, no account.

**[Fly at 0sfs.github.io](https://0sfs.github.io/)** · [Source](https://github.com/0SFS/fly) · AGPL-3.0-only
